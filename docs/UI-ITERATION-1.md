# UI 迭代 1

本轮仅完成用户指定的五项界面调整，业务数据模型和任务规则沿用 v0.1.0。

## 已实现

1. **滚动条固定占位**：主内容、侧栏、首页分区、弹窗正文、备注、选项列表和时间列表均保留独立滚动槽；有无溢出不改变内容宽度。统一 12px 槽位、细圆角滑块、明暗主题颜色及悬停状态，无系统箭头按钮。
2. **自定义选择控件**：状态、优先级、项目、阶段、任务关联和时段筛选均使用自绘下拉列表；较长列表支持搜索。日期支持本地日历、月切换、年份输入、今天和清除；精确时间支持显式小时/分钟选择及手工输入，不填充虚构时间。
3. **响应式与字号**：字号改用 rem 与随视口变化的基础字号；设置新增「紧凑 / 标准 / 大号」，持久化到 SQLite。布局覆盖窄屏、竖屏、矮屏、桌面、超宽及 4K，窄屏侧栏展开为覆盖式导航。桌面窗口最小尺寸调整为 320×360。
4. **侧栏动画**：按 SWUST-OC 的 `cubic-bezier(.22,1,.36,1)` 缓动规则，使用 420ms 连续宽度过渡及标签淡出。快速反向操作从当前位置继续，不瞬间切列宽或用 display:none 隐藏标签。窄屏支持遮罩关闭、侧栏内关闭及 Escape，并将焦点移入导航。
5. **弹窗闪烁修复**：进入动画移动整个 dialog 外壳，正文使用独立、固定占位的滚动视口；标题和操作栏不参与正文滚动。消除了旧版在滚动容器内平移内容造成的短暂额外溢出。进入使用 320ms 轻移和轻微缩放，退出 180ms；嵌套弹窗保持焦点边界，支持减少动态效果实时切换。

动画参考：`swust-oc-web-ppt/references/design-and-motion.md`。本轮沿用桌面应用结构，仅复用动效原则，不采用 PPT 的固定画布或大幅翻页距离。

## 主要文件

- `src/components/Controls.tsx`：自定义下拉、日历及时间选择器，使用浏览器 top layer 保证不被容器裁切，外观由应用绘制。
- `src/components/Modal.tsx`：外壳动画、独立滚动区和可中断关闭。
- `src/components/motion.ts`：缓动参数及实时系统动态偏好订阅。
- `src/ui.css`、`src/styles.css`：主题滚动条、响应式布局与字号体系。
- `src/App.tsx`：平滑侧栏、窄屏导航、单一主滚动区及无重影的页面进入。
- `src/pages/Settings.tsx`、`src/state.tsx`、`src/data/repository.ts`：字号选择和 SQLite 持久化。
- `scripts/ui-smoke.mjs`：针对本轮问题的真实 Tauri WebView2 验收。测试仅添加并移除自己的临时任务，恢复原外观偏好，不替换用户业务数据。
