# 项目删除修复

当前规则：删除项目同时删除其全部阶段、任务（含未分阶段、已完成和已归档任务）及这些任务的关联日程。不再把子任务解绑成独立任务。其他项目、原独立任务和无关联日程不受影响。

第 5 版迁移移除旧 project_delete_detach，增加 project_delete_contents。所有子项删除在同一条项目 DELETE 的触发器中执行，任一子项删除失败会回滚整次操作。既有迁移不重写。

删除确认显示阶段、任务、关联日程数量，并明确不可撤销。需要保留内容时使用归档项目，仍可恢复。

39 项测试通过，覆盖删除范围、归档项、未分阶段项、不相关数据保留、失败回滚和归档行为。实际 Tauri 窗口也已验证确认数量、取消不删除、确认后级联删除及重载持久化。另有 2 项 Rust 导入恢复测试通过。

此前已经解绑的历史任务没有可靠的现存项目关联，不自动删除，以免误删独立任务。迁移本身只替换触发器，不删除任何现有业务记录。

本机备份与验证记录保存在 Git 忽略的 artifacts/project-delete-fix。

Windows EXE 和 NSIS 安装包已更新并构建成功。最终发布程序离线启动、完整关闭与重启、归档恢复通过，外部请求及页面错误为 0。再次核对磁盘数据库，修复前的现有业务记录保持不变。
