# Local Workbench v0.1.0

首个正式公开版本：冻结当前无需应用注册、登录的本地工作台与 AI 助手，作为后续迭代的固定基线。

## 这次发布了什么

- **本地任务与时间管理**：独立任务、项目阶段、DDL、批量操作、归档恢复、多个执行日程、重要事件和休息日。
- **时间工作台**：14 天地平线、今日时间轴、截止倒计时、项目进展，以及月历与年历；自定义布局会在重启后保留。
- **AI 工作伙伴**：DeepSeek 流式 Markdown 对话、实时业务查询、工具调用、多轮操作预览；写入必须由用户确认并通过业务校验和事务执行。
- **语音输入**：点击录音 → 停止识别 → 可编辑回填 → 手动发送，不会直接发送消息或创建任务。
- **外观和数据**：7 种强调色、明暗模式、字体调整、自绘控件、减少动态效果、SQLite 迁移、JSON 导入导出和恢复前备份。

**无需登录的是 Local Workbench 本身。** AI 与语音需要联网、用户自己的 DeepSeek API Key 和服务额度；不附带共享密钥或免费推理额度。核心任务管理可完全离线使用。

## 下载与安装

- `Local-Workbench_0.1.0_windows-x64-setup.exe`：推荐，Windows 10/11 x64 安装包，附带 WebView2 离线安装器。
- `Local-Workbench_0.1.0_windows-x64.zip`：应用文件与许可证，要求系统已有 WebView2。解压后运行 `local-workbench.exe`。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。

安装包未做代码签名，Windows 可能提示未知发布者。请确认下载来源并核对校验值：

```powershell
Get-FileHash .\Local-Workbench_0.1.0_windows-x64-setup.exe -Algorithm SHA256
```

ZIP 不是数据便携模式。两种分发方式均使用 `%APPDATA%\org.localworkbench.desktop\workbench.db`；更换程序目录不会隔离数据库。当前开发版用户也会使用同一数据库，建议先在设置中导出备份。

## 已知边界

- 没有自动更新、云同步、系统提醒或重复任务规则。
- 业务数据库与备份未加密；API Key 存于 Windows 凭据管理器。
- JSON 导入是完整替换，不是合并；业务导出不包含助手历史、API Key 或外观偏好。
- AI 可能理解偏差，请核对操作预览；语音为整段识别、最长两分钟，仍需用户在自己的麦克风环境中验收。
- 本次验证不代表已覆盖所有 Windows 设备、系统版本或硬件输入设备。
