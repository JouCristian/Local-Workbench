# Local Workbench v0.1.0 上手与验收指南

适用版本：2026-11-13 完成的本地版本，包含任务批量操作、删除关联日程、复合日程管理、首页24小时时间表，以及月历／年历、个性化颜色和可持久化布局。最新功能见第15节。

这份指南分为功能说明和手动验收两部分。前半部分可以按需查阅；希望全面验收时，建议先备份，再按第 12 节的顺序操作。

## 1. 启动与第一次使用

### 1.1 启动方式

日常使用任选一种：

- 双击项目内的 `src-tauri/target/release/local-workbench.exe`。
- 运行 `src-tauri/target/release/bundle/nsis/Local Workbench_0.1.0_x64-setup.exe` 安装，再从安装后的入口启动。

直接运行 EXE 需要本机已有 WebView2 Runtime；安装包包含 WebView2 离线安装器。普通使用不需要 Node.js、Rust 或开发服务器，也不需要账号、网络连接。

直接运行版与安装版使用同一个 Windows 用户数据目录。数据不保存在 EXE 旁边，移动 EXE 不等于迁移数据；迁移到其他电脑请用 JSON 导出、导入。

请使用本轮新版。旧版程序可能无法读取已经升级的数据库。

### 1.2 验收前先备份

1. 打开左侧「设置」。
2. 在「数据与备份」中点击「创建备份」。
3. 将 JSON 保存到你能找到的位置。
4. 确认页面出现备份成功提示和保存路径。

后续测试建议使用 `[验收]` 开头的项目和任务，方便搜索及清理。暂时不想替换现有数据时，直接新建测试记录即可，无须导入示例。

## 2. 先分清五种内容

| 内容         | 解决的问题                 | 例子与关系                                                         |
| ------------ | -------------------------- | ------------------------------------------------------------------ |
| 项目         | 一段持续工作的总目标       | 「整理学习资料」；包含阶段和任务                                   |
| 阶段         | 项目在一段日期内的工作部分 | 「资料收集」；必须属于项目，可包含任务                             |
| 任务         | 具体要完成什么             | 「整理参考目录」；可以独立，也可属于项目，项目内可以暂不分配阶段   |
| 日程         | 准备哪天、哪个时段执行     | 「今天上午整理目录」；可关联任务，也可独立存在；一个任务可多次安排 |
| 事件／休息日 | 某一天需要注意的日期标记   | 「发布日」「休息一天」；不参与任务完成率                           |

### 2.1 截止日期和执行日期独立

例如：任务的截止日期是后天，计划今天上午做一部分、明天下午继续。

- 在任务中设置后天的 DDL。
- 为同一任务分别创建今天上午和明天下午两条日程。
- 改日程日期不会修改任务 DDL；修改 DDL 也不会移动日程。
- 有 DDL 且从未关联任何日程的任务，在到期当天显示「待安排」及截止信息。
- 已在其他日期安排过的任务，在截止当天显示「截止提醒」，不再标记为待安排。
- 截止当天已有执行日程时，截止信息直接附在执行条目上，不额外重复一行。
- 没有今日安排、今天也不到期的普通待办，不会被自动塞进首页「今天」。

### 2.2 完成、归档和删除不同

| 操作     | 是否改变完成状态 | 日常视图                             | 数据是否保留               |
| -------- | ---------------- | ------------------------------------ | -------------------------- |
| 完成     | 变为已完成       | 可通过已完成筛选或「显示已完成」查看 | 保留任务和日程             |
| 归档     | 保持原状态       | 从日常任务、总览和关联日程视图移出   | 保留，可恢复               |
| 删除任务 | 记录被删除       | 移出                                 | 任务及全部关联日程永久删除 |

归档适合保留历史但暂时不想看到的内容。删除目前没有撤销或回收站。

## 3. 窗口、导航与通用控件

### 3.1 窗口与侧栏

- 顶部标题栏空白区域可以拖动窗口。
- 右上角提供最小化、最大化／还原、关闭按钮。关闭会退出窗口，并非缩到系统托盘。
- 内容区左上角的侧栏按钮用于收起、展开导航。
- 四个主入口为「总览」「任务与项目」「日程」「设置」。
- 侧栏项目列表可快速进入具体项目；目前最多展示前 8 个活动项目，其余在项目页查看。
- 小窗口会采用紧凑导航；打开导航抽屉后，可以通过遮罩或关闭按钮收起。

### 3.2 编辑与保存

- 点击任务标题编辑任务；点击日程内容编辑日程；点击事件条编辑事件。
- 项目通过项目标题行右侧的更多按钮编辑，阶段展开后有「编辑阶段」。
- 在弹窗中点击「保存任务」「保存项目」等按钮后才会写入数据库。
- 「取消」、关闭按钮或 Escape 会放弃尚未保存的表单修改。
- 正在保存或批量处理时，相关按钮会暂时禁用。
- 校验失败时看弹窗内错误提示，修改后再次保存。

### 3.3 日期与时间输入

- 日期可直接输入，也可点击日历图标使用应用自带日历。
- 当前年份可输入 `11月18日`、`11-18` 或 `11/18`；指定年份可输入 `2026-11-18`。
- 日期离开输入框后统一显示为「11月18日」；非当前年份显示年份。
- 日历支持切换月份、编辑年份和「选择今天」；可选日期字段提供「清除日期」。
- 时间使用 24 小时制，可输入 `09:30`、`22:00`，也可用时间选择器选小时和分钟。
- 仅日期不需要补时间；上午、下午、晚上不会被自动换算为具体小时。
- 精确日程必须填写开始时间，结束时间可留空。填写结束时间时，必须晚于开始时间。
- 跨午夜安排目前需要拆成两天。例如 23:00 至次日 01:00，不能放进同一条日程。

时间轴上的块会保留足够的点击高度；没有填写结束时间，并不代表应用替你保存了结束时间。以编辑窗口中的值为准。

### 3.4 下拉框与键盘

- 下拉选项较多时会出现「搜索选项」；当前规则为超过 7 个选项时显示。
- 打开后可用上／下方向键移动，Enter 选择，Home／End 跳到首尾。
- Escape 关闭当前下拉、日历或弹窗；有内层浮层时先关闭内层。
- Tab／Shift+Tab 在可操作控件间移动，编辑弹窗内会保持焦点循环。
- `Ctrl+N` 在没有编辑弹窗时新建任务；快速添加输入框内按 Enter 添加任务。
- 日期输入框获得焦点时，`Alt+↓` 可以打开日历。

普通编辑输入框不会在弹窗出现时自动获得输入焦点。点击后显示统一的蓝色高亮描边和光晕，取消焦点时渐隐。

## 4. 总览：从时间出发查看工作

### 4.1 日期与摘要

顶部显示本机当天日期和星期，右侧「新建任务」打开任务编辑器。

摘要按实际数据组合，例如「今天 3 项安排 · 7 天内有 2 个截止 · 1 项逾期」。没有对应内容的摘要项不会显示。

这里的「今天安排」是今天尚未完成的展示条目数，不是数据库中全部任务的数量。同一任务今天安排了两次，可以算作两项执行。

### 4.2 时间地平线

展示从今天开始的连续 14 天：

- 日期数字：对应本地日历日期。
- 圆点：当天有任务截止，颜色表示紧急程度或完成状态。
- 底部细条：当天日程数量的相对大小。
- 「休」：当天有休息日标记。
- 小旗：当天有重要事件。
- 点击某一天：进入「日程」并选中该日。

日期条包含已完成任务的截止标记和未归档的日程记录；完成任务后标记可能变色，安排量细条不要求归零。它和只统计未完成条目的首页摘要，口径不同。

### 4.3 「今天」24小时时间表

左侧是可独立滚动的00:00–23:00时间表；初次进入靠近当前小时，可上下滚动查看整天。这里合并当天日程和当天到期任务：

- 「未指定时段」「上午」「下午」「晚上」「待安排」「截止提醒」仅在有内容时显示，位于精确小时轴上方；向顶部滚动即可查看。模糊时段不被分配具体小时。
- 精确开始时间显示在时间线上，并有随本机时间更新的「现在」标记。
- 已关联今日日程的任务，不会再作为一条独立 DDL 任务重复出现；已安排在其他日期的任务在到期当天仅显示截止提醒。
- 同一任务的不同执行时间属于不同日程，会分别保留。
- 重要事件和休息日显示在当天内容中。
- 勾选任务前的完成按钮，会更新同一任务在其他页面的状态及项目进度。
- 开启「显示已完成」可查看当天已完成内容，并取消完成。

独立日程只有日程内容，没有任务完成勾选框。如果需要完成状态，应创建任务并将日程与它关联。

### 4.4 截止倒计时

- 汇总未完成、未归档且有 DDL 的任务，不限于今天或未来 7 天。
- 按截止日期和时间从近到远排列，逾期项在前。
- 标签可能显示「今天截止」「还剩 5 天」「还剩 2 小时」「逾期 1 天」等。
- 红色表示逾期，橙色表示今天截止，黄色表示未来 7 天内截止，较远日期使用较弱颜色。
- 仅日期的今天截止任务，不会因没有填写时间而在白天被判为逾期；本地日期进入下一天后才算逾期。
- 可直接勾选完成，或点击标题编辑。

### 4.5 项目进展

- 每个活动项目一行，点击项目名称进入该项目。
- 每个分段对应一个阶段，段内填充表示该阶段任务完成比例。
- 阶段是否为当前阶段由起止日期决定；重叠阶段可以同时高亮。
- 点击阶段分段可编辑阶段。
- 右侧「阶段一／共 2 段 · 2 项待完成」中的待完成数，指右侧所指阶段的未完成任务数量，并非必然是整个项目的未完成总数。
- 多个阶段同时进行时，右侧采用按日期排列后较后的活动阶段；无活动阶段时采用最近的未来阶段，全部结束后采用最后阶段。没有阶段时统计项目未完成任务。

首页的今日安排和截止倒计时各有固定预留滚动槽。桌面窗口会根据可用高度调整两个区域，尽量让项目进展也直接可见；较小窗口或项目较多时仍可整页滚动，以保证所有内容可访问。

## 5. 独立任务

进入「任务与项目」→「独立任务」。它和「项目」是两个平级分类。

### 5.1 快速添加

1. 在「记下一件事，按 Enter 添加…」中输入标题。
2. 按 Enter 或点击「添加任务」。
3. 新任务默认为待办、中优先级，没有 DDL，没有日程。
4. 点击标题，补充详细信息。

快速添加不会根据标题自动解析日期，也不会自动安排到今天。

### 5.2 完整创建与编辑

点击「新建任务」，可以设置：

| 字段     | 使用说明                               |
| -------- | -------------------------------------- |
| 任务标题 | 必填，最多 300 字                      |
| 状态     | 待办、进行中、已完成                   |
| 优先级   | 低、中、高；中优先级通常不额外显示标签 |
| 截止日期 | 可留空                                 |
| 截止时间 | 可留空，但不能在没有截止日期时单独设置 |
| 所属项目 | 选择「独立任务」表示不属于项目         |
| 所属阶段 | 选定项目后可选，也可暂不分配           |
| 备注     | 可多行，最多 20,000 字                 |

保存后，独立任务行会显示具体 DDL 和代表性执行安排。一个任务有多条日程时，任务行不会列出所有日程：优先展示今天或之后的一条；没有未来安排时展示最近的历史安排。完整执行计划到日程页逐日查看。

### 5.3 筛选、搜索与状态

- 「未完成」同时包含待办和进行中。
- 「已完成」只看完成任务；「全部」包含未归档的所有状态。
- 搜索匹配标题与备注，可与状态筛选组合。
- 点击完成圆圈：待办／进行中变为已完成；再次点击变回待办。
- 如果希望恢复为「进行中」，在编辑窗口中选择该状态。
- 完成后，在「未完成」列表中消失属于正常筛选结果，可切换到「已完成」查看。

### 5.4 为任务安排时间

点击任务行右侧的日历按钮，打开「任务日程」窗口，当前任务已固定关联。

1. 已有日程会全部列出，可直接修改每条的执行日期、时间安排及精确起止时间。
2. 点击「添加一条日程」可连续新增多条，无须反复关闭、新建。
3. 每条的「标题与备注」可展开编辑。
4. 移除按钮暂时把该条从草稿中移除；对已有日程可「撤回移除」。
5. 最后点击「保存日程」，一次保存全部安排；若会删除已有日程，会再显示确认框。
6. 点击「取消」不写入草稿改动。重复时间、无效日期等错误会阻止整批保存，不会成功一部分。

保存不更改任务DDL。若这些日程已在其他位置被修改，窗口会拒绝覆盖，关闭并重新打开后再编辑。

## 6. 项目与阶段

### 6.1 创建项目

在「任务与项目」中点击「新建项目」，填写标题、备注并保存。也可从侧栏项目标题旁的加号或总览底部创建。

项目本身没有单独的起止日期输入框，其时间结构由各阶段表达。项目色由应用自动分配，同一项目的侧栏圆点、任务左侧色条和进度使用同色；当前没有手动选色功能。

### 6.2 创建阶段

1. 切换到「项目」，找到对应项目。
2. 点击「添加阶段」或「添加第一个阶段」。
3. 填写阶段标题、所属项目、开始日期、结束日期。
4. 保存。

起止日期可以相同，表示单日阶段；不同阶段可以重叠。阶段按日期排列，不会因重叠而覆盖或移动其他阶段。

点击阶段标题前的箭头展开、收起。展开后可「编辑阶段」「添加任务」。已有任务的阶段不能直接移动到另一个项目。

阶段日期不会自动成为内部任务的 DDL，也不会自动生成执行日程。

### 6.3 项目内任务

- 阶段内「添加任务」会预选项目和阶段。
- 项目底部「添加项目任务」会预选项目，暂不分配阶段。
- 暂不分配阶段的任务显示在「未分配阶段」。
- 更改任务所属项目时，阶段选择会清空，需要重新选择新项目的阶段。
- 把所属项目改为「独立任务」并保存，可以主动把任务移出项目。
- 「全部项目」仅显示项目内容，不包含独立任务。
- 筛选具体项目后，可以使用快速添加；这种方式创建的任务不自动分配阶段。
- 在「全部项目」下使用完整新建任务窗口时，请检查「所属项目」，避免未指定归属。

项目标题行显示完成数量和百分比。完成率根据任务完成状态计算，归档不等于完成；已单独归档的任务仍可能计入项目的历史任务总数和完成率。

## 7. 日程、重要事件与休息日

### 7.1 找到某一天

进入「日程」后可：

- 点击顶部 7 天条选择同周日期。
- 点击左右箭头跳到上一周、下一周。
- 点击「今天」回到本机当天。
- 在日期输入框输入日期，或打开日历跨月、跨年选择。
- 从总览 14 天地平线直接进入某一天。

当天安排分为有内容才出现的模糊时段、待安排任务，以及 08:00–23:00 小时刻度。08:00 之前的精确安排单独列出，不会丢失。空闲时间保留留白。

### 7.2 新建日程

1. 先选日期，再点击「新建日程」。
2. 「关联任务」选择已有任务，或保留「独立日程」。
3. 填写标题、执行日期、时间安排及备注。
4. 若选择「精确时间」，填写开始时间，按需填写结束时间。
5. 点击「保存日程」。

关联任务时，如果标题还为空，会自动填入任务标题。日程时间线主要展示关联任务的标题；不同的日程标题可作为补充说明显示。

时段有「全天／未指定」「上午」「下午」「晚上」「精确时间」。前三类模糊时段以及未指定安排不占用虚构的小时位置。

同一天可以存在多条安排，精确时间允许重叠；重叠事件会分列显示。它们不会相互覆盖，也不会被自动顺延。一个任务可以安排多天，或者同一天不同的时段／开始时间。

### 7.3 编辑、完成与删除日程

- 点击日程内容修改日期、时段、任务关联或备注。
- 修改为模糊时段时，原先的精确开始、结束时间会清空。
- 关联任务的完成按钮改变的是整个任务的状态，其所有关联日程都会体现完成状态；当前没有「只完成这一次执行」的独立状态。
- 开启「显示已完成」查看完成任务的安排。
- 编辑窗口中的「删除日程」只删除这一条日程，不会删除任务，也不会删除该任务的其他日程。
- 右侧「?」在按钮附近弹出说明，窗口不足时调整方向，不应跑到左上角。
- 精确安排使用项目色浅填充和色条；独立安排使用主蓝色。明暗主题均保留文字与时间的可读性。

### 7.4 重要事件与休息日

1. 在日程页点击「标记事件」。
2. 输入事件标题和日期。
3. 选择「重要事件」或「休息日」，按需填写备注。
4. 保存。

对应日期会显示旗标或「休」，当天也会出现事件条。点击事件条可编辑、删除。

休息日是提示标记，不会阻止当天创建任务或日程，也不会自动调休、移动 DDL。重要事件和休息日均无任务完成状态。

## 8. 防止重复与合理的多次安排

### 8.1 任务防重

同一项目归属、同一阶段内，不允许新建同名活动任务。独立任务之间也执行该规则。

- 比较标题时会忽略空白、英文字母大小写，并规范化全角／半角等兼容字符。
- 同一标题出现在不同项目或不同阶段，可以代表不同工作，允许存在。
- 已完成但未归档的任务仍参与防重；先搜索「全部」，避免误以为它不存在。
- 恢复归档任务若会与现有任务重名，会提示冲突，先改名或处理现有记录再恢复。

### 8.2 日程防重

- 同一任务、同一天、同一时段和开始时间，不能重复添加。
- 独立日程按规范化标题、日期、时段和开始时间判断是否重复。
- 相同任务的不同日期、不同模糊时段或不同精确开始时间，允许存在。
- 两个不同任务在同一时刻执行，允许存在。

如历史数据已有同时间重复日程，时间线会合并显示；打开保留的日程时，编辑窗口可能显示旧重复安排及「移除重复项」。逐项确认后，只删除被选中的重复记录，当前日程与任务保留。

## 9. 批量操作

### 9.1 选择范围

1. 在「独立任务」「项目」或「归档」中，先确定分类、状态、项目和搜索条件。
2. 点击页面上方「批量选择」。
3. 逐项点击方形选择框，或点击任务标题选择／取消选择。
4. 也可以点击「全选当前结果」，查看「已选 N 项」。

选择模式的方框只表示选中，不表示完成。普通完成圆圈和行内归档、安排按钮会暂时让位给批量操作。

「全选当前结果」包含整个筛选结果，可能包括屏幕下方、尚未滚到的任务，以及收起阶段中的匹配任务。它不是只选当前屏幕可见的几行。

- 独立任务页只选择独立任务。
- 项目页只选择符合项目及状态筛选的项目任务，不混入独立任务。
- 归档页的批量选择只针对任务，不选择「已归档项目」卡片。
- 切换分类、状态、项目或修改搜索，会退出选择模式并清空选择。
- 点击「取消选择」可主动退出。没有选中项或操作不适用时，按钮会禁用。

### 9.2 操作说明

| 位置／按钮           | 结果                                 | 确认规则                     |
| -------------------- | ------------------------------------ | ---------------------------- |
| 活动任务／完成       | 所选任务变为已完成                   | 直接执行                     |
| 活动任务／重新打开   | 所选任务变为待办                     | 直接执行，不自动恢复为进行中 |
| 活动任务／归档       | 隐藏所选任务及关联日程，状态保留     | 有未完成任务时确认           |
| 归档任务／恢复       | 返回原分类、项目、阶段，完成状态保留 | 有重名冲突时拒绝整批恢复     |
| 活动或归档任务／删除 | 永久删除所选任务及全部关联日程       | 始终确认，显示任务和日程数量 |

批量操作在一个数据库事务中完成；遇到错误整批回滚，不会只成功一部分。失败后查看错误提示、解决冲突，再重新操作。操作成功后会退出选择模式，并刷新总览、进度与列表。

## 10. 归档、恢复与删除的完整影响

### 10.1 归档入口

- 已完成任务行的归档图标：直接归档。
- 任务编辑窗口「归档任务」：可归档完成或未完成任务，需确认。
- 项目编辑窗口「归档项目」：需确认。
- 多个任务可通过批量选择归档。

归档项目后，其阶段、任务和任务关联日程一起退出日常视图。任务原状态及单独的归档状态保留。

### 10.2 恢复入口

进入「任务与项目」→「归档」：

- 「已归档项目」中点击「恢复项目」。
- 「已归档任务」中点击「恢复」，或批量恢复。
- 也可打开归档记录的编辑窗口使用恢复按钮。

项目归档期间，子任务不会全部拆散显示到「已归档任务」中。先恢复项目，再处理其中单独归档过的任务。

恢复项目不会顺便取消子任务原先独立的归档状态。恢复任务也不把已完成变成待办。

### 10.3 删除影响表

| 删除对象         | 一起删除                                                 | 保留                                                        |
| ---------------- | -------------------------------------------------------- | ----------------------------------------------------------- |
| 项目             | 全部阶段、所属任务（含归档任务）、这些任务的全部关联日程 | 其他项目、原有独立任务及无任务关联的日程                    |
| 阶段             | 阶段记录                                                 | 其中任务留在原项目的「未分配阶段」，任务 DDL 与关联日程保留 |
| 任务             | 任务及其所有日期、所有时段的关联日程                     | 所属项目、阶段、其他任务及独立日程                          |
| 一条日程         | 当前日程                                                 | 关联任务和其他日程                                          |
| 重要事件／休息日 | 当前事件记录                                             | 任务与日程                                                  |

删除确认中点「取消」不会执行删除。历史上已经与任务脱离关联的独立日程，不会在升级时被自动猜测和清理。

## 11. 设置、备份、恢复与本地数据

### 11.1 外观

- 主题：浅色、深色、跟随系统。
- 字体：紧凑、标准、大号，同时随窗口宽度适配。
- 外观选择保存在本机，重新启动仍保留。
- 「个性化颜色」提供雾蓝、青绿、森林、紫罗兰、玫瑰、琥珀、石墨7种强调色，适配深浅主题。它改变按钮、选中导航和焦点，不改变逾期、完成或项目颜色的含义。
- 动效遵循 Windows 减少动态效果偏好，应用里没有单独的动画开关。Windows 11 可在「设置 → 辅助功能 → 视觉效果 → 动画效果」切换，再观察应用。

### 11.2 JSON 导出与创建备份

「导出 JSON」和「创建备份」都生成完整、可阅读的 JSON，主要区别是默认文件名和操作用途：

- 包含项目、阶段、任务、日程、事件及归档状态。
- 不受当前搜索、筛选影响，不是只导出屏幕上的记录。
- 不包含本机主题、字体设置。
- 保存位置由你选择；取消文件选择不会写入文件。

### 11.3 JSON 导入与恢复备份

**导入和恢复都是完整替换当前业务数据，不是追加、合并。导入示例同样会替换。**

1. 点击「导入 JSON」或「恢复备份」。
2. 选择 Local Workbench 格式的 JSON 文件。
3. 应用先检查格式、UUID、字段、真实日期和关联关系。
4. 有效文件会显示项目、阶段、任务、日程、事件数量及替换说明。
5. 检查后点击「备份当前数据并导入」，或点击「取消」。
6. 成功后查看页面提示，其中有原数据自动备份路径。

恢复前会先保存原有业务数据到自动备份 JSON；写入使用事务，失败回滚。主题和字体设置保留。

想撤回一次导入：再次点击「恢复备份」，选择上一步提示的原数据备份文件，确认恢复。

普通随手写的任务数组不能直接导入。当前文件需要完整的 Local Workbench 顶层结构，文件文本限制约 30 MB，每类记录最多 100,000 条。手动修改 JSON 时还需保证 UUID、日期和引用关系合法。

### 11.4 通用示例与本机个人计划

- 「导入示例」使用虚构的通用示例，适合初次熟悉。
- 仓库通用文件在 `examples/generic.json`。
- 个人初始化计划请使用自己的 JSON，可放在 `private/` 或使用 `*.local.json` 后缀，通过「导入 JSON」选择。公开仓库不附带个人计划；导入前务必核对是否要替换现状。
- `private/` 和 `*.local.json` 被 Git 忽略，不随公开源码或发行包分发。

### 11.5 本地存储与版本

设置页「本地存储」显示数据库记录数量和实际数据目录，底部显示应用版本、MIT 与离线说明。

默认位置：

```text
%APPDATA%\org.localworkbench.desktop\workbench.db
%APPDATA%\org.localworkbench.desktop\backups\before-restore-*.json
```

可按 `Win+R` 输入 `%APPDATA%\org.localworkbench.desktop` 打开目录。应用内目录字段可选中文字复制。

记录总数包含归档内容，所以可能大于日常页面显示的数量。自动备份目前不会自动轮换，需自行定期清理。数据库及 JSON 未加密；卸载、迁移或替换电脑前，先导出一份独立备份。

## 12. 建议的完整手动验收流程

下面全部使用新建的 `[验收]` 记录，不需要覆盖现有数据。「今天＋N天」以你实际验收时的本地日期为准。

### A. 建立一组测试数据

先完成第 1.2 节备份，再按表创建：

| 对象       | 名称与设置                                                           |
| ---------- | -------------------------------------------------------------------- |
| 项目       | `[验收]资料整理`                                                     |
| 阶段一     | `[验收]准备`，今天至今天＋2天                                        |
| 阶段二     | `[验收]交付`，今天＋1天至今天＋4天，与阶段一重叠                     |
| 阶段一任务 | `[验收]收集资料`、`[验收]整理提纲`                                   |
| 阶段二任务 | `[验收]撰写说明`、`[验收]检查交付`；最后一个设置今天＋4天 16:00 截止 |
| 独立任务 A | `[验收]提交阅读记录`，今天＋2天 18:00 截止                           |
| 独立任务 B | `[验收]日常整理`，今天截止，不填截止时间                             |

给这些任务添加日程：

| 日程 | 关联与时间                              |
| ---- | --------------------------------------- |
| 1    | 收集资料，今天上午                      |
| 2    | 提交阅读记录，今天 10:00–10:30          |
| 3    | 同一个提交阅读记录，明天下午            |
| 4    | 整理提纲，今天 10:00，与第 2 条重叠     |
| 5    | 独立日程 `[验收]散步`，今天晚上         |
| 6    | 标记事件 `[验收]检查日`，明天，重要事件 |
| 7    | 标记事件 `[验收]休息`，后天，休息日     |

### B. 验收日常功能

| 编号 | 操作                                    | 预期结果                                                                                |
| ---- | --------------------------------------- | --------------------------------------------------------------------------------------- |
| B01  | 独立任务和项目之间切换                  | 独立任务不出现在全部项目中；项目任务不混入独立任务                                      |
| B02  | 修改任务备注、优先级和状态              | 保存后重新打开，内容保留；进行中仍属于未完成                                            |
| B03  | 搜索 `[验收]`，切换未完成／已完成／全部 | 搜索和状态共同生效；清空搜索能恢复完整结果                                              |
| B04  | 查看总览                                | 今日安排、截止倒计时、14天地平线、项目进展同时存在                                      |
| B05  | 查看今天安排                            | 上午有收集资料；10:00有两条不同任务；晚上有散步；今天到期但未安排的日常整理出现在待安排 |
| B06  | 查看总览与明日、后日                    | 今天的执行不把后天DDL改成今天；明日旗标、后日「休」可见                                 |
| B07  | 完成「收集资料」                        | 测试项目由0%变25%，准备阶段完成1/2；首页对应任务同步完成／隐藏                          |
| B08  | 开启显示已完成，取消「收集资料」完成    | 任务恢复待办、项目回0%，其他任务状态不受影响                                            |
| B09  | 编辑提交阅读记录的第一条日程，改到晚上  | 只移动这次执行；第二条日程及后天DDL保留                                                 |
| B10  | 打开日程编辑器检查上午／下午            | 没有被填入虚构的09:00或14:00                                                            |
| B11  | 同一任务、同一天、同一时段重复新增      | 保存被拒绝；改成不同日期或不同时间可以保存                                              |
| B12  | 同一分类／阶段重复创建同名任务          | 保存被拒绝；不同项目或阶段允许同名                                                      |
| B13  | 给精确日程设置早于开始的结束时间        | 提示错误，不保存；不填结束时间可以保存                                                  |
| B14  | 输入不存在的日期、空标题                | 提示校验错误，原有数据不改变                                                            |

测试期间若日期已过当天某个精确 DDL，倒计时变红属于正常行为。

### C. 验收批量操作

1. 在「独立任务」搜索 `[验收]`，确认只有测试用的两项独立任务匹配。
2. 点击「批量选择」→「全选当前结果」，应显示已选 2 项。
3. 点击「完成」，再切到「已完成」，两项应都存在。
4. 再次选择这两项，点击「重新打开」，两项均变为待办。
5. 在未完成筛选下重新全选，点击「归档」，确认显示有 2 项尚未完成；先取消，两项应保留。
6. 再归档并确认，到「归档」搜索 `[验收]`，选择两项恢复；任务原状态和日程保留。
7. 在「项目」搜索 `[验收]` 并进入批量选择，检查全选数量只包含测试项目的 4 项任务，不应算入独立任务。
8. 选中后切换状态、分类或修改搜索，选择模式应退出，旧选择不应带入下一处。

### D. 验收归档与删除联动

以下操作只对 `[验收]` 记录进行：

| 操作                               | 预期结果                                                     |
| ---------------------------------- | ------------------------------------------------------------ |
| 完成一个任务，归档后恢复           | 仍是已完成，不变成待办                                       |
| 归档测试项目                       | 日常项目、子任务、关联日程隐藏；归档页保留项目；独立任务仍在 |
| 恢复测试项目                       | 阶段、任务、日程回到原关系和原完成状态                       |
| 删除一条关联日程，先取消、再确认   | 取消时保留；确认只删这一条，任务及其他日程不变               |
| 删除准备阶段                       | 阶段消失，其任务移到原项目未分配阶段，关联日程保留           |
| 删除提交阅读记录，先取消           | 任务和其两条日程均保留                                       |
| 再次删除提交阅读记录并确认         | 任务和所有关联日程删除，散步独立日程保留                     |
| 批量删除其余测试独立任务           | 确认数量正确，只删除所选任务及关联日程                       |
| 删除测试项目                       | 阶段、项目任务及关联日程一起删除，不跑到独立任务中           |
| 删除测试重要事件、休息日和散步日程 | 对应标记和安排消失，其他数据保留                             |

### E. 验收动效与界面

1. 总览 → 设置：设置从下方进入；设置 → 总览：总览从上方进入。
2. 总览点击未来某日：日程内容从右方进入。
3. 日程选择同一周内较早、较晚日期：选中块从原位置滑到新格子。
4. 用日历跨周向未来选择，再返回过去：选中块分别从左侧、右侧进入。
5. 在独立任务、项目、归档及状态标签之间往返：横向切换方向符合排列顺序。
6. 快速连续切页、途中反向：最终页面正确，无长期重影或透明层挡点击。
7. 展开阶段再收起：非线性收拢，结束后不反弹。
8. 打开编辑器、日期和任务下拉，再关闭：位置稳定，没有闪烁错位。
9. 点击搜索与普通输入框：高亮视觉一致，没有叠成双框；焦点高亮有出现和消失过渡。
10. 完成某时段最后一个任务，再取消完成：分组与行平顺变化，不闪回。
11. 拉长、拉宽、缩小窗口，切换字体和深浅主题：能滚到操作按钮，正文无不合理横向溢出；弹窗出现时主内容不因滚动条跳动。
12. 在 Windows 关闭动画效果：内容仍完整可操作，不依赖动画结束才出现。

页面纵向滚动槽会占用固定空间，不应因弹窗或内容多寡导致主布局左右跳。下拉、日历、时间选择器是应用自定义控件；选择文件时弹出的 Windows 文件对话框属于系统文件管理入口。

### F. 验收备份、恢复、离线和重启

1. 保留一条自己的测试任务及日程，记录状态；创建一份新的验收备份。
2. 关闭整个应用，重新启动，检查任务、DDL、日程、状态和外观仍在。
3. 断开网络，创建／编辑任务、安排日程、完成任务、切换页面及导出 JSON，应仍可用。
4. 先恢复网络也可以继续；数据不需要等待云端同步。
5. 如要验证导入，先确认已有最新备份，再修改测试任务标题，随后导入修改前那份验收备份。
6. 在确认框核对将替换的数据数量，先取消一次，当前标题不应变化。
7. 再导入并确认，标题恢复为备份中的内容；页面显示原数据自动备份路径，外观设置保持。
8. 选择无效 JSON，或复制备份后故意写一个非法日期再导入，应提示失败，不替换当前数据。
9. 测试结束后只清理自己的 `[验收]` 记录。若希望恢复到验收开始前的完整状态，使用最开始的备份；这也会舍弃验收期间你另外新增的真实修改，请自行决定。

## 13. 常见疑问与当前边界

| 现象／问题                         | 说明与处理                                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------------ |
| 新建任务后总览今天看不到           | 给它安排今天的日程，或确认它是否今天到期；普通待办不会自动变成今日计划               |
| 完成后列表中找不到                 | 切到已完成／全部；总览与日程开启显示已完成                                           |
| 任务或日程突然不见                 | 先检查分类、项目、搜索、状态、所选日期和归档；再检查所属项目是否已归档               |
| 任务还在但某次安排没了             | 检查日程日期是否被改动、是否删除了该条日程；日程和任务是不同记录                     |
| 今天有安排但日期条数量和摘要不同   | 日期条计日程，摘要计当天未完成展示条目；待安排DDL和多次执行会造成口径差异            |
| 归档未完成任务后项目不是100%       | 归档不等于完成，历史任务仍可能参与项目完成比例                                       |
| 重要事件／休息日没有完成按钮       | 它们是日期标记，不是任务                                                             |
| 独立日程无法勾选完成               | 如需完成状态，请关联任务                                                             |
| 恢复归档任务提示重名               | 搜索当前全部任务，改名或处理同分类、同阶段的冲突后再恢复                             |
| 项目进展右侧数量与项目总任务数不同 | 右侧主要显示所指阶段的剩余数，项目总完成情况去项目页查看                             |
| 删除后想找回来                     | 目前只能通过删除前的完整备份恢复，没有回收站；恢复会替换当前业务数据                 |
| 页面显示本地读取错误               | 阅读顶部错误信息，点击「重试读取」；仍失败时保留错误截图与出现步骤，不要手动删数据库 |

当前版本没有系统到期通知、循环任务、拖拽日历、跨日单条日程、任务依赖、云同步、数据加密、撤销删除或独立的日程完成状态。DDL 颜色和倒计时是应用内提示，不会自动弹出 Windows 提醒。

## 14. 如何反馈验收结果

每个问题建议提供：

```text
验收编号：例如 E04 / C07
所在页面：日程 / 项目 / 设置……
前置条件：日期、筛选、主题、字体、是否批量选择

实际结果：出现了什么；能否重复

```

视觉问题可补充窗口大小、Windows 显示缩放比例，以及是否开启系统动画效果。数据问题先保留现场和备份，再记录步骤，避免反复删除或导入导致现场变化。

## 15. 月历、年历与自定义总览布局

### 15.1 月历与年历

1. 在总览顶部点击小日历图标「查看月历」，进入当月；日程页同名按钮进入当前所选日期所在月份。
2. 月历按周一至周日排列，包含相邻月份的补齐日期；圆点为截止事项，短方点为执行安排，旗标为重要事件，「休」为休息日。
3. 日期格内显示部分标题和安排数；当天内容较多时，点击日期进入现有日程页查看全部。
4. 点击「全年」收拢为12个月的年历；选择某月展开成月历，再选择某天进入当天日程。
5. 左右箭头切换前后月或年，「本月／本年」回到当前日期所在范围；「返回总览」回首页。

月历与年历是时间概览，日程页是每天的执行与编辑入口。三个层级使用同一份本地数据，修改、完成、归档或删除后，标记与数量会跟随变化。月历中不重复添加一套创建和编辑操作。

由具体到总体采用收拢过渡，进入某月或某日采用围绕入口的展开过渡；前后月份仍按时间方向左右切换。系统减少动态效果时直接切换内容。

### 15.2 调整总览布局

- 时间地平线保持固定，不参与拖拽。
- 拖动「今天」和「截止倒计时」之间的竖向分隔柄，调整左右宽度。
- 拖动上方两块与「项目进展」之间的横向分隔柄，调整上下高度。
- 三块内容都能内部滚动，项目很多时也不会把下面内容无限推长。滚动槽固定预留，避免出现时挤动页面。
- 松开分隔柄后自动保存。切换页面、关闭程序后再启动仍保留比例。
- 分隔柄可通过Tab获得焦点，用相应方向键调整；Home或双击恢复当前方向的默认比例。
- 总览顶部「恢复默认布局」按钮恢复全部默认比例：左右为3:2，上下为72:28；恢复过程平滑滑动。
- 拖动有合理的比例限制，避免把内容区压没。该布局为分区尺寸调整，模块位置保持固定。
- 窄屏改用纵向排列并隐藏分隔柄，保留宽屏比例；放大回宽屏后重新应用保存的布局。

个性化颜色和布局属于当前设备的设置，不包含在业务JSON中；导入或恢复业务备份不会覆盖它们。
