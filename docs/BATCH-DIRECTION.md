# 批量任务与方向交互

## 本轮行为

- 删除任务会同步删除全部关联日程；单项与批量共用数据库触发器。独立日程不受影响。
- 点击任务页「批量选择」，使用方形选择框或「全选当前结果」。支持完成、重新打开、归档、恢复、删除。删除和归档未完成任务需确认；删除弹窗给出任务及关联日程数量。
- 选择范围由当前分类、状态、项目与搜索共同决定；条件变化清空选择。项目全选排除独立任务。归档项目的子任务先恢复项目后才可恢复。
- 批量写入通过 Rust SQLx 单连接事务，数据库错误、记录已删除或恢复重名等错误会整批回滚；不会发生成功一半的状态。
- 侧栏切页使用上下方向，横向标签与日程使用左右方向。总览日期入口以今日为基准判断前后。
- 日期条只保留一个选中块，同周直接平移，跨周向未来从左侧进入、向过去从右侧进入。保留现有缓动与中途反向能力，遵循减少动态效果偏好。
