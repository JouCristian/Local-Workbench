# 月历、年历与个性化布局

## 产品边界

月历／年历是现有日程的时间概览，复用活动数据和日期逻辑。总览和日程提供小日历按钮；年展开为月、月展开为日，日仍由原日程页管理。无第二套日历数据库、事件编辑器或重复任务。

日历使用周一起始的固定6周月网格，年历显示12个月；支持前后导航、跨年、回本月／本年和返回总览。日程、截止、重要事件、休息日具有各自标记，归档内容隐藏。年份边界为1900–9999。

## 动效

共用`ViewSwitch`的可取消过渡：保留当前页与最近退场页。新增深度轴，具体视图收拢到总体视图，进入月份或日期则围绕所选入口展开。使用现有760ms进入／540ms退出与`cubic-bezier(.22,1,.36,1)`。前后月份沿左右轴，侧栏仍沿上下轴。减少动态效果直接显示结果。

恢复布局使用同一760ms非线性缓动，对真实分区比例逐帧插值；拖拽即时跟随指针，可以中断恢复动画。支持方向键、Home、双击及丢失指针捕获时回到已保存值。

## 持久化

- SQLite既有`settings`表增加`accent`、`dashboard-layout`两项值，无需修改业务表或已有迁移。
- 7种强调色具有明暗配色，保留状态色及项目色；偏好在显示真实数据前应用，避免先显示默认再跳变。
- 默认左右60:40、上下72:28，合法范围分别32–72%、40–82%；无效配置回退默认。
- 拖拽结束后串行持久化，重启读取；恢复默认也写库。窄屏不覆盖已保存的桌面比例。
- 项目进展有独立滚动容器，三个内容区均固定预留12px滚动槽；地平线不参与拖拽。
- 个性化偏好不在业务JSON内，导入／恢复业务数据保留本机偏好。

## 验证

48项前端测试、8项Rust测试通过。真实Tauri专项验证月／年／日数据与层级关系、两个分隔柄、单调的恢复动画、键盘调整、项目列表滚动、切页与SQLite重载、14组颜色对比度、320px窄屏和减少动态效果。

进入月历的逐帧采样确认旧视图持续收拢、新视图展开显现，透明度总和未出现空白帧；快速年／月反向操作后没有遗留退场页。检查的是实际WebView帧，不保证低性能机器在任何负载下均无掉帧。

补充修复了“年历返回总览后立刻再进入月历”复用旧年历状态的问题：日历入口使用独立访问标识；中断时保留较可见的背景，并把被替换视图的透明度接续到新视图，避免交叉淡入中途丢失一层画面。退场生命周期按当前序列的时限清理，不使用可能来自已中断动画的完成回调。该路径的逐帧连续性和现有动效回归通过。

7种强调色在两种主题的主色文字及主按钮对比度均达到4.5:1，逾期色不变。测试只操作随机UUID记录，恢复原偏好，业务数据逐表比较。截图和报告位于Git忽略的`artifacts/calendar-personalization/`。
